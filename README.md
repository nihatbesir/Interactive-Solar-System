# 🪐 Interactive Solar System / İnteraktiv Günəş Sistemi.

## 🇦🇿 Azərbaycan Dili

HTML, CSS və Vanilla JavaScript ilə hazırlanmış interaktiv və çoxyönlü Günəş Sistemi simulyasiyası.

### 🇦🇿 Xüsusiyyətlər:
- **8 Planet və Günəş:** Bütün planetlər Günəşə olan elmi məsafə sırası ilə yerləşdirilib.
- **3 Dil Seçimi:** Azərbaycan, Türk və İngilis dilləri arasında anında keçid.
- **Dartılan Lampa (Tünd/İşıqlı Rejim):** İnteraktiv lampa ipini dartaraq rejimi dəyişmək imkanı.
- **Məlumat Paneli:** Planetlərə kliklədikdə fırlanma dayanır və planet haqqında ətraflı məlumat açılır.
- **Xarici Kitabxanasız:** Tamamilə təmiz HTML, CSS və JS istifadə olunub.

### 🛠️ Texnologiyalar:
- HTML5
- CSS3 (Keyframe animasiyaları & CSS dəyişənləri)
- JavaScript ES6+

## 🇹🇷 Türkçe

HTML, CSS ve Saf JavaScript kullanılarak geliştirilmiş etkileşimli Güneş Sistemi simülasyonu.

### 🇹🇷 Özellikler:
- **8 Gezegen ve Güneş:** Tüm gezegenler Güneş'e olan bilimsel sıralamaya göre yerleştirilmiştir.
- **3 Dil Desteği:** Türkçe, Azerbaycan Türkçesi ve İngilizce arasında anında geçiş.
- **Çekilebilir Lamba (Karanlık/Aydınlık Mod):** İnteraktif lamba ipini çekerek temayı değiştirme özelliği.
- **Bilgi Paneli:** Gezegenlere tıklandığında yörünge durur ve detaylı bilgi paneli açılır.
- **Kütüphanesiz:** Tamamen saf HTML, CSS ve JS kullanılmıştır.

### 🛠️ Kullanılan Teknolojiler:
- HTML5
- CSS3 (Keyframe animasyonları & CSS değişkenleri)
- JavaScript ES6+

## 🇬🇧 English

An interactive Solar System simulation built with HTML, CSS, and Vanilla JavaScript.

### 🇬🇧 Features:
- **All 8 Planets & Sun:** Arranged in accurate scientific order from the Sun.
- **Multi-Language Support:** Instant switching between Azerbaijani, Turkish, and English.
- **Pull-String Lamp (Dark/Light Mode):** Toggle theme using an interactive animated lamp switch.
- **Informative Side Panel:** Clicking on a planet pauses the orbit and displays details about it.
- **Zero Dependencies:** Pure HTML, CSS, and JavaScript with no external libraries.

### 🛠️ Tech Stack:
- HTML5
- CSS3 (Keyframe animations & CSS variables)
- JavaScript ES6+
